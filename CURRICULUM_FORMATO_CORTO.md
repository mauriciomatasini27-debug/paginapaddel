# Padel Listo - Proyecto para Currículum

## Descripción del Proyecto

**Padel Listo** - Landing Page PWA para reserva de canchas de pádel. Aplicación web progresiva con funcionalidad offline, integración de mapas interactivos y autenticación con Google.

**Repositorio:** https://github.com/mauriciomatasini27-debug/paginapaddel.git

---

## Tecnologías Utilizadas

### Frontend
- HTML5, CSS3, JavaScript (Vanilla ES6+)
- Tailwind CSS
- Progressive Web App (PWA)
- Service Workers

### APIs y Servicios
- Google Sign-In API
- Google Maps API (Places)
- QRCode.js
- Google Fonts (Inter)

---

## Funcionalidades Principales

✅ Progressive Web App instalable en móviles  
✅ Funcionalidad offline con Service Worker  
✅ Autenticación con Google

✅ Generación de códigos QR  
✅ Diseño responsive y dark mode  
✅ Cache inteligente de recursos
